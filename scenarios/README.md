# Scenarios

这里收集真实世界里的 AI Agent 使用场景。

场景不是功能清单。场景更像是一段故事：

> 谁，在什么情况下，遇到了什么麻烦，希望 Agent 怎么帮忙。

## 推荐文件命名

```txt
行业-角色-场景.md
```

例子：

```txt
sales-customer-follow-up.md
hr-resume-screening.md
consulting-proposal-draft.md
```

## 场景模板

```md
# 场景名称

## 一句话简介

## 背景

## 当前流程

## 痛点

## 理想中的 Agent

## 输入

## 输出

## 使用频率

## 价值判断

## 风险与边界

## 延伸想法
```

## 王六的判断标准

一个适合 Agent 的好场景，通常有这些特征：

- 信息来源分散
- 操作重复但不完全机械
- 需要理解上下文
- 有明确产出物
- 人类需要最终判断
- 做好了能明显省时间或提高质量
