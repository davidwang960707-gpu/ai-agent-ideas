# 销售客户跟进 Agent

## 一句话简介

帮助销售从会议纪要、聊天记录和 CRM 里自动整理客户状态、风险和下一步行动。

## 背景

销售同学每天会和多个客户沟通，信息分散在微信、飞书、会议纪要、邮件和 CRM 里。每周复盘时，需要手动整理客户进展。

## 当前流程

1. 翻聊天记录
2. 查会议纪要
3. 更新 CRM
4. 整理客户阶段
5. 写下一步计划
6. 给主管同步风险

## 痛点

- 信息太散
- 容易漏掉客户承诺和待办
- 复盘耗时
- 风险发现不及时

## 理想中的 Agent

Agent 可以自动汇总客户相关信息，生成客户状态卡片，包括当前阶段、关键诉求、风险点、下一步行动和建议话术。

## 输入

- 客户聊天记录
- 会议纪要
- CRM 字段
- 历史跟进记录

## 输出

- 客户进展摘要
- 风险提醒
- 下一步行动
- 建议跟进话术

## 使用频率

每天或每周。

## 价值判断

每周节省 2-3 小时，减少漏跟进，提高销售管理质量。

## 风险与边界

- 不能直接替销售承诺价格或合同条款
- 涉及客户隐私的数据需要脱敏和权限控制
- 关键判断仍需要销售确认

## 延伸想法

后续可以做成客户健康度评分、商机推进建议、自动生成周报。
