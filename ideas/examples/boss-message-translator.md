# 老板消息翻译器 Agent

## 一句话

把老板一句模糊的话，翻译成可能的真实意图、行动项和风险提醒。

## 为什么想到它

很多工作消息都很短，比如：

```txt
这个方案再优化一下。
```

但背后可能有很多含义：结构不清楚、数据不够、重点不对、老板没安全感、客户可能不买账。

## 可能适合谁

- 产品经理
- 运营
- 市场
- 售前
- 咨询顾问
- 初入职场的同学

## 它可能怎么工作

用户输入一段消息，Agent 输出：

- 可能真实意图
- 需要补充的问题
- 建议行动项
- 推荐回复
- 风险提醒

## 可能的价值

减少误解，提高沟通效率，让人少走弯路。

## 目前最大的不确定性

不同公司和不同老板的表达习惯差异很大，需要结合上下文才能更准。
