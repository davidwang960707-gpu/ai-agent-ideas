# Requirements

这里收集已经比较明确的 AI Agent 需求。

如果说 `scenarios/` 是“发生了什么”，那 `requirements/` 就是“我们想让 Agent 做什么”。

## 需求模板

```md
# 需求名称

## 目标

这个 Agent 要解决什么问题？

## 用户

谁会使用它？

## 触发方式

用户什么时候会用它？

## 输入

需要哪些资料、数据、文件或系统权限？

## 核心能力

- 能力 1
- 能力 2
- 能力 3

## 输出

Agent 需要交付什么结果？

## 成功标准

什么情况下算它做得好？

## 边界

什么事情不应该由它做？

## Demo 形态

如果先做一个最小 Demo，应该长什么样？
```

## 需求分级

| 等级 | 含义 |
| --- | --- |
| P0 | 高频、强痛点、容易验证 |
| P1 | 有价值，但需要更多信息 |
| P2 | 有趣，先观察 |
| P3 | 脑洞很美，落地待定 |
