# 会议纪要转行动计划 Agent

## 目标

把会议纪要自动整理成结构化行动计划，减少会后无人跟进、事项丢失的问题。

## 用户

项目经理、产品经理、销售、咨询顾问、团队负责人。

## 触发方式

会议结束后，用户上传会议纪要或录音转写文本。

## 输入

- 会议纪要
- 参会人名单
- 项目信息
- 历史任务记录

## 核心能力

- 识别会议结论
- 提取行动项
- 判断负责人
- 识别截止时间
- 标记风险和待确认问题
- 生成跟进计划

## 输出

- 行动项列表
- 负责人
- 截止时间
- 风险事项
- 待确认问题
- 可复制到项目管理工具的任务文本

## 成功标准

- 80% 以上行动项被正确识别
- 用户修改成本低于从零整理
- 输出能直接用于项目跟进

## 边界

- 不自动替用户发送任务
- 不替代项目负责人做最终判断
- 不处理未经授权的敏感会议内容

## Demo 形态

一个网页输入框：粘贴会议纪要后，自动生成行动计划表格和风险摘要。
